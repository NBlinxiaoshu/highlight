# 小黄笔 Highlight

把长视频与播客变成可高亮、可回听、可做笔记的深度阅读稿。当前支持 YouTube 和小宇宙，Bilibili 适配中。

英文项目名：`highlight`。中文产品名：**小黄笔**。

## 它能做什么

- **快速模式**：只读节目简介和现成时间轴，不转写音频，快速判断值不值得听。
- **完整精读**：默认使用阿里云百炼 `qwen-audio-3.0-asr-flash-filetrans`，返回时间戳与说话人编号；再结合节目简介和开场自我介绍匹配主持人与嘉宾姓名。Supadata 作为兼容选项保留。
- **原文 / 摘要双栏目**：默认先读原文，当前播放段落自动高亮并跟随滚动。
- **精修逐字稿**：不删减口述信息，只修正明显断句和孤立碎片，将原始转写整理成可连续阅读的正式段落。
- **自然跳过片头**：片头文字逐段淡出，以一条轻量分割线进入正文；没有常驻提示卡，仍可随时展开片头原文。
- **悬浮目录**：原文左侧使用 GPT 风格的横杠索引；山谷轮廓实时跟随鼠标，悬停显示标题与摘要，点击跳转后自然收回。
- **三级阅读标注**：Case 使用带标题的整段卡片，金句使用黄色行内荧光笔，能说明成本、规模、时间跨度和变化的关键事实局部加粗。
- **阅读工具栏**：Case、金句、搭子划线可分别显隐，并可切换上一条/下一条；搭子旁注可收藏到笔记。
- **自由复制**：原文支持正常拖选、复制和粘贴；只有普通点击段落时才跳转播放。
- **文档式节目笔记**：不额外堆叠核心观点、产品观察或收听建议，只用标题和缩进要点整理节目真实讲述的事件、论据、案例与结论。
- 点击摘要时间戳或任意文字稿段落，可让当前页面的播放器跳到对应位置。
- 摘要缓存在 Chrome 本地；当前用户提供的 No.214 Word 原文也会持久缓存，确保没有转写服务时仍可直接阅读。项目已加入本机历史列表及可独立部署的账号/资料库后端骨架；未确认 HTTPS 服务地址前不会上传用户数据。

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹：`/Users/linxiaoshu/Desktop/博客摘要/highlight`
5. 扩展会打开设置页。自己填写 DeepSeek API Key；转写推荐填写阿里云百炼 DashScope API Key，也可切回 Supadata。不要把 Key 发到聊天或提交进源码。

与 YouTube Digest 相同，摘要固定调用 DeepSeek 的 `deepseek-v4-flash`，并使用非思考模式。没有开放 Base URL 或模型名输入框，避免误配置。

## 使用

1. 打开一个 YouTube 视频或公开的小宇宙单集。
2. 点击浏览器工具栏里的“小黄笔”，或页面右下角的“精读这期”。
3. 选择“只读节目文案”或“生成完整精读”。完整模式完成后，可在“原文”和“摘要”之间切换。

项目内置了 No.214 的用户提供 Word 原文作为当前效果样例。原始 750 个粗分段已整理为 284 个可读段落，其中 10:03 后有 268 个正文段落；正文字符完整保留，约四分之一正文会得到 Case、金句或无标签的局部加粗标注。打开对应单集时会写入浏览器本地缓存，用来预览鼠标山谷目录、渐隐片头、播放联动、阅读工具栏和共读搭子；其他节目使用设置中选择的转写服务。

Qwen Audio 3.0 文件转写适合播客和访谈，支持时间戳、上下文和说话人分离。当前短节目测试使用单个异步任务；长节目的真正渐进展示仍需要服务端切片，因为单个阿里异步任务不会返回中间结果。完整设计见 [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md)。

## 数据与隐私

- 页面标题、节目文案或逐字稿会发送给 DeepSeek 生成摘要。
- 完整模式会把公开音频 URL 发送给用户选择的转写服务；阿里方案经过用户自己的后端切片处理。
- 密钥和摘要保存在 `chrome.storage.local`；当前不会自动上传。
- 仓库包含可独立部署的历史记录服务器，但云端同步默认关闭，也不内置任何 API Key。

具体说明见 [PRIVACY.md](PRIVACY.md)。使用第三方 API 前，请同时阅读对应服务的隐私条款与计费规则。
